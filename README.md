# Перекрёстки — куб

Интерактивная 3D-схема сцены «Перекрёстки» (Foundry VTT): шесть больших тайлов A–F как грани куба
и все двусторонние телепорты между их сторонами (21 проход, 12 рёбер).

Открыть: https://sigiller.github.io/crossroads-cube/

- «Как в сцене» / «Куб» — раскладка как в Foundry или собранный куб.
- Наведение на линию, грань или строку таблицы подсвечивает связи.
- Блок «На кубе» включает буквы граней, подписи сторон и номера проходов.

Страница самодостаточная (`index.html`, карты встроены), three.js грузится с jsDelivr.
